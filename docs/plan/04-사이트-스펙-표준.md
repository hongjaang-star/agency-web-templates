# 사이트 스펙 표준

사이트마다 docs/site-spec.md 하나를 단일 기준으로 둔다. 기획, 디자인, 카피, 이미지, 코드, SNS 소재, 인수인계 문서가 모두 이 파일에서 파생된다. Claude 외에 ChatGPT, Gemini, 이미지 생성 도구로 작업을 나눌 때도 이 파일을 그대로 붙여 넣으면 같은 방향의 결과를 얻는다.

## 스펙 항목

각 항목은 짧은 값으로 쓰고 설명 문장은 필요한 곳에만 둔다. 예시는 medical-dermatology(lumiere) 기준이다.

| 구분 | 필드 | 예시 |
|---|---|---|
| 메타 | 슬러그, 변형, 레벨, 스펙 버전 | medical-dermatology, lumiere, L1, 1.0 |
| 비즈니스 | 상호, 지역, 주요 서비스, 차별점 | 뤼미에르 피부과(가상), 강남역, 리프팅·색소·여드름, 전문의 1:1 진료 |
| 목표 | 1차 목표, 전환 행동, 측정 지표 | 예약 전환, 네이버 예약 클릭, 예약 클릭률 |
| 타깃 | 페르소나 2개 (나이, 상황, 고민, 결정 요인) | 30대 후반 직장인, 기미·탄력 고민, 신뢰와 자연스러운 결과 중시 |
| 메시지 | 핵심 메시지 1문장, 슬로건, 근거 3개 | 피부 본연의 빛을 정직하게 / 전문의 직접 진료, 정품 시술, 사후 관리 |
| 톤앤매너 | 형용사 3개, 문장 길이, 금지 표현 | 차분한, 정중한, 절제된 / 과장·비교·효과 보장 금지 |
| 비주얼 | 테마 프리셋, 컬러 토큰, 서체, 모서리, 모션 | lumiere, ivory·ink·gold, Cormorant·나눔명조·Pretendard |
| 이미지 | 공통 프롬프트, 장면 목록, 비율, 금지 요소 | 자연광, 웜 화이트, 클로즈업 / 시술 장면·전후 비교 금지 |
| 정보구조 | 페이지 목록, 메인 섹션 순서 | 8페이지, homeSections 12개 |
| SEO | 핵심 키워드, title 패턴, schema 타입 | 강남역 피부과, "지역 업종 상호 \| 서비스", MedicalClinic |
| 규제 | 적용 법규, 필수 고지, 심의 여부 | 의료법 광고 규정, 부작용 고지, 실제 납품 시 심의 |
| 기능 | 모듈, 외부 연동 | 지도, 카카오톡 채널, 네이버 예약 |
| 운영 | 수정 주기, 담당, 유지보수 플랜 | 월 1회 이벤트 갱신, 에이전시, 베이직 |

## AI 작업 계약

각 생성 단계는 스펙을 입력으로 받고 정해진 형식으로만 출력한다. 출력 형식이 고정되어 있어야 어떤 AI가 만들어도 코드와 문서에 바로 들어간다.

| 단계 | 입력 | 출력 형식 | 검증 |
|---|---|---|---|
| 리서치 | 업종, 지역, 레퍼런스 URL | research.md 양식 | 사람 검토 |
| 스펙 | research.md | site-spec.md 양식 | G1 승인 |
| 카피 | site-spec.md, 섹션 목록 | src/data 형식의 TypeScript 객체, 섹션별 글자 수 제한 | 타입 검사, 금지 표현 검사 |
| 이미지 | 이미지 공통 프롬프트, 장면 목록 | 지정 파일명과 비율의 WebP | 파일명·비율 자동 검사 |
| SNS 캡션 | site-spec.md, 데모 URL | 캡션 3안, 해시태그 15개, CTA 1문장 | G3 승인 |

## 문서 체계

문서는 독자별로 나누고 같은 정보는 한 곳에만 쓴다. 나머지 문서는 그 한 곳에서 자동으로 만든다.

- site-spec.md (기획자, AI 도구): 사이트의 단일 기준. S2에서 작성.
- README.md (개발자): 실행, 빌드, 구조. 템플릿 공통 문서에 업종 값만 자동 치환.
- handover.html (고객, 인수 업체): 수정 방법과 운영 가이드. 스펙과 데이터에서 자동 생성.
- CHANGELOG.md (유지보수 담당): 변경 기록. 커밋 메시지에서 자동 생성.
- CLAUDE.md, SKILL.md (AI 코딩 도구): 작업 규칙과 절차. 공통 패키지에서 관리.

## 업종 규제 사전

업종별 금지 표현과 필수 고지를 rules/{대분류}.md 파일로 관리하고 카피 생성 프롬프트와 QA 검사에 함께 쓴다. 실제 납품 전 최종 판단은 해당 분야 심의기구나 전문가가 한다.

| 대분류 | 주요 확인 사항 |
|---|---|
| medical | 치료 효과 보장, 타 기관 비교, 무료·할인을 내세운 환자 유인, 시술 전후 사진, 부작용 고지 |
| pro (법률·세무·노무) | 승소율·성공률 표시, 최고·유일 같은 단정 표현, 자격 표기 정확성 |
| 공통 | 가격 표시 기준, 후기 사용 동의, 개인정보 수집 동의, 이미지·폰트 라이선스 |
