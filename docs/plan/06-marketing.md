# 마케팅과 수익화

포트폴리오는 그 자체가 영업 도구다. 매일 만드는 사이트가 곧 SNS 콘텐츠가 되고, 모든 콘텐츠는 데모 사이트의 "이 디자인으로 시작하기" 문의로 이어지도록 설계한다.

## 포지셔닝

타깃은 홈페이지가 없거나 오래된 지역 소상공인과 전문직 사무소다. 메시지는 업종 전문 템플릿, 빠른 오픈, 매월 관리 세 가지로 정리한다. 예를 들면 "세무사무소 전용 홈페이지, 5일 안에 오픈하고 매달 관리해 드립니다."와 같은 형식이다.

## 상품과 가격

가격은 시장 조사 전 가정치다. 첫 5건 계약까지 문의 반응을 보며 조정한다. 난이도 레벨이 그대로 상품 등급이 된다.

| 상품 | 구성 | 가격 (가정) | 납기 |
|---|---|---|---|
| 스타트 (L1) | 템플릿 1종, 5페이지, 콘텐츠 교체, 도메인 연결, 기본 SEO | 59만~99만원 | 5일 |
| 스탠다드 (L2) | 스타트 구성, 상담·견적 폼, 네이버·구글 등록, 애널리틱스 | 129만~199만원 | 7일 |
| 프리미엄 (L3~L4) | 스탠다드 구성, 게시판 또는 예약, 디자인 맞춤 조정 | 250만원부터 | 14일 |
| 유지보수 구독 | 호스팅, 월 수정 2~5회, 보안·백업, 월간 리포트 | 월 3만~10만원 | 매월 |
| 부가 서비스 | 네이버 플레이스 세팅, 블로그 SEO 글, SNS 소재, 광고 랜딩 | 건별 10만~50만원 | 건별 |

### 수익 구조 원칙

- 구독 우선: 제작비보다 유지보수 구독 누적(MRR)을 핵심 지표로 본다. 제작 계약에 첫 3개월 구독을 기본 포함한다.
- 템플릿 재판매: 같은 템플릿을 다른 지역의 같은 업종 고객에게 판매할 수 있어 건당 원가가 계속 내려간다.
- 단계적 업셀: L1 고객에게 L2 폼, L3 게시판을 순서대로 제안한다.

## 채널 전략

수익이 빨리 나는 순서로 채널을 연다. 마켓플레이스는 첫 계약, SNS는 인지도, 블로그는 검색 유입을 맡는다.

| 채널 | 역할 | 콘텐츠 | 빈도 |
|---|---|---|---|
| 크몽·숨고 | 첫 계약 확보 | 업종별 패키지 상품, 포트폴리오 링크 | 0주차 등록, 주 1회 갱신 |
| 인스타그램 | 포트폴리오 노출, 문의 | 신작 캐러셀, 스크롤 릴스 | 캐러셀 매일, 릴스 주 3회 |
| 스레드 | 제작 과정 공유, 인지도 | 하루 작업 기록, 업종 팁 | 매일 |
| 유튜브 쇼츠 | 노출 확장 | 릴스 재활용 | 주 3회 |
| 네이버 블로그 | 검색 유입 | "업종 + 홈페이지 제작" 정보 글, 사례 | 주 2회 |
| 당근 비즈프로필 | 지역 고객 | 지역 업종 사례, 오픈 소식 | 주 1회 |

## 콘텐츠 포맷

모든 포맷은 사이트 스펙과 테마 토큰에서 자동 생성하고, 이미지에는 가상 업체 데모임을 표기한다.

- 신작 공개 캐러셀: 표지(업종·컨셉), 데스크톱 화면, 모바일 화면, 핵심 기능, 가격·문의 CTA 5장. sns 명령으로 생성.
- 스크롤 릴스: 메인 페이지 15초 스크롤과 업종 문구 자막. sns 명령으로 생성.
- 업종 인사이트: "세무사무소 홈페이지에 꼭 필요한 섹션 5가지" 같은 정보형 캐러셀. 리서치 카드에서 생성.
- 제작 과정: 스펙에서 완성까지 작업 화면 타임랩스.
- 변형 비교: 같은 업종 변형 2종을 나란히 보여 주고 투표를 유도.

## 전환 퍼널

단계마다 측정 지점을 두고, 주간 리뷰에서 전환율이 가장 낮은 단계부터 개선한다.

| 단계 | 장치 | 측정 지표 |
|---|---|---|
| 노출 | SNS 게시물, 블로그, 마켓 상품 | 도달, 노출수 |
| 관심 | 프로필 링크에서 포트폴리오 사이트(업종 필터)로 이동 | 프로필 클릭, 방문 |
| 탐색 | 템플릿 데모 사이트 | 체류 시간, 조회 페이지 수 |
| 문의 | 데모 상단 "이 디자인으로 시작하기", 업종·변형이 자동 입력된 문의폼 | 문의 전환율 |
| 상담 | 자동 응답(패키지 안내, 사전 설문), 상담 예약 | 상담 예약률 |
| 계약 | 견적서·계약서 자동 초안 | 계약 전환율, 평균 계약액 |
| 유지 | 유지보수 구독, 월간 리포트 | 구독 유지율, MRR |
| 추천 | 고객 사례 콘텐츠, 추천 할인 | 추천 계약 수 |

## 영업 자동화

문의 이후 과정도 생산 파이프라인과 같은 방식으로 자동화한다.

1. 문의폼이 접수되면 PHP 공통 API가 관리자에게 알리고, 문의자에게 업종별 패키지 안내와 사전 설문 링크를 자동 발송한다.
1. 사전 설문(상호, 서비스, 사진 보유 여부, 희망 오픈일) 응답으로 site-spec 초안을 자동 생성한다.
1. 상담에서 패키지가 정해지면 견적서와 계약서 초안을 템플릿에서 자동 생성한다.
1. 계약 후에는 생산 파이프라인과 같은 절차로 납품하고, 데모의 가상 데이터를 고객 데이터로 교체한다.

## 수익 시나리오

가정치 기반 시나리오다. 실제 문의 전환율이 나오는 4주차에 다시 계산한다.

| 시점 | 신규 계약 | 평균 제작비 (가정) | 구독 누적 | 월 매출 (가정) |
|---|---|---|---|---|
| 1개월차 | 1건 | 80만원 | 1곳, 월 5만원 | 약 85만원 |
| 2개월차 | 3건 | 120만원 | 4곳, 월 5만원 | 약 380만원 |
| 3개월차 | 5건 | 130만원 | 9곳, 월 5만원 | 약 695만원 |
| 6개월차 | 6건 | 150만원 | 25곳, 월 6만원 | 약 1,050만원 |

## 첫 30일 실행 체크리스트

아래 항목을 끝내면 수익화 기반이 갖춰진다.

- 포트폴리오 사이트(업종 필터, 데모 링크, 문의폼) 오픈
- 인스타그램 비즈니스, 스레드, 유튜브, 네이버 블로그 계정 개설과 프로필 통일
- 크몽·숨고에 업종별 패키지 3개 등록
- 캐러셀·썸네일 디자인 템플릿 3종 제작
- L1 템플릿 15개 공개, 신작 캐러셀 15개 발행
- 문의 자동 응답 문구와 사전 설문 작성
- 4주차 지표 리뷰 후 가격과 채널 조정
