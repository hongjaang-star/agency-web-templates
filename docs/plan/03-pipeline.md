# 생산 파이프라인

업종 하나를 하루 안에 기획부터 SNS 발행까지 끝내는 표준 절차다. 모든 단계는 입력과 산출물을 파일로 남기고, 사람은 세 개의 승인 게이트(G1 컨셉, G2 품질, G3 발행)에서만 판단한다.

## 단계별 절차

소요 시간은 L1 기준이며 자동화 단계가 올라갈수록 줄어든다.

| 단계 | 시간 | 입력 | 산출물 | 자동화 |
|---|---|---|---|---|
| S0 업종 선정 | 전날 10분 | 업종 백로그 | 확정 슬러그와 변형 | 백로그 점수 자동 정렬 |
| S1 리서치 | 30분 | 레퍼런스 URL, 키워드 | research.md | AI 초안, 사람 검토 |
| S2 사이트 스펙 | 30분 | research.md | site-spec.md (G1 승인) | AI 초안, 사람 승인 |
| S3 콘텐츠 | 60분 | site-spec.md | 카피 데이터 파일, 이미지 세트 | AI 생성, 이미지 자동 최적화 |
| S4 구현 | 90분 | 스펙, 콘텐츠 | 블록 조합, 테마 토큰, 신규 블록 | Claude Code와 스킬 |
| S5 QA | 30분 | 빌드 결과 | QA 리포트 (G2 승인) | 자동 검사와 체크리스트 |
| S6 배포 | 자동 | main 병합 | 데모 URL, 포트폴리오 목록 갱신 | GitHub Actions |
| S7 SNS 소재 | 자동 | 데모 URL, 스펙 | 캐러셀 5장, 릴스 1개, 캡션 | 스크린샷·합성 스크립트, AI 캡션 |
| S8 발행·기록 | 10분 | 소재 (G3 승인) | 예약 발행, 진행 현황 갱신 | 발행 API 또는 예약 도구 |

## 업종 선정 기준 (S0)

업종 백로그의 후보를 네 항목으로 점수화해 높은 순서로 착수한다. 점수는 백로그 시트에서 자동 계산한다.

| 항목 | 비중 | 판단 기준 |
|---|---|---|
| 수요 | 35% | 해당 업종 사업자 수, "업종 + 홈페이지 제작" 검색량 |
| 레벨 적합성 | 25% | 현재 운영 중인 레벨 이하인지 |
| 블록 재사용률 | 25% | 기존 블록으로 구성 가능한 섹션 비율 |
| SNS 화제성 | 15% | 시각적 매력, 계절·이슈 연관성 |

## 스타일 일관성 시스템

컨셉에서 화면, 이미지, 문구, SNS 소재까지 같은 기준을 쓰도록 모든 산출물을 사이트 스펙 한 곳에서 파생시킨다. 스펙을 거치지 않고 만든 산출물은 스타일이 흔들리므로 허용하지 않는다.

1. 컨셉: site-spec의 목표, 타깃, 핵심 메시지, 톤 형용사 3개를 정한다.
1. 디자인 토큰: 테마 프리셋을 고르고 컬러 5~6개, 서체 2개, 모서리, 여백 밀도를 토큰으로 확정한다.
1. 이미지: 스펙의 이미지 공통 프롬프트(조명, 색온도, 구도, 인물 연령대)를 모든 장면 프롬프트 앞에 붙여 생성한다.
1. 카피: 톤 가이드와 업종 금지 표현 사전을 프롬프트에 넣고 섹션별 글자 수 제한을 지킨다.
1. SNS 소재: 사이트와 같은 토큰으로 캐러셀 템플릿을 렌더링해 사이트와 SNS가 같은 인상을 준다.

### 테마 프리셋 라이브러리

업종마다 처음부터 디자인하지 않고 검증된 프리셋에서 출발해 조정한다. 초기 프리셋은 6종이며 생산하면서 늘린다.

| 프리셋 | 인상 | 어울리는 업종 |
|---|---|---|
| lumiere | 화이트, 샴페인 골드, 세리프 | 피부과, 에스테틱, 웨딩 |
| trust | 네이비, 화이트, 정돈된 산세리프 | 세무, 법률, 노무, 컨설팅 |
| craft | 웜 그레이, 우드 톤, 넓은 여백 | 인테리어, 건축, 가구 |
| fresh | 화이트, 민트, 둥근 모서리 | 치과, 청소·방역, 동물병원 |
| cozy | 크림, 브라운, 손글씨 포인트 | 카페, 베이커리, 펜션 |
| bold | 블랙, 단일 원색 포인트, 큰 타이포 | 피트니스, 스튜디오, 자동차 정비 |

## 완성 기준 (DoD)

아래 항목을 모두 통과해야 1개 완성으로 집계한다.

- 페이지 5개 이상, 메인 섹션 8개 이상, 모바일 360px에서 가로 스크롤 없음
- Lighthouse 성능·SEO·접근성·권장사항 모두 90 이상
- 모든 페이지 고유 title과 description, 구조화 데이터 검증 통과
- 업종 금지 표현 없음, 필수 고지 포함, 가상 업체 데모 표기
- research.md, site-spec.md, handover 문서, CHANGELOG 갱신
- SNS 소재 세트(캐러셀 5장, 릴스 1개, 캡션 3안) 생성
- 진행 현황과 포트폴리오 목록에 등록

## 사이트별 산출물 폴더

모든 사이트는 같은 폴더 구조를 쓴다. 다른 AI 도구나 다른 작업자도 같은 위치에서 같은 파일을 찾는다.

| 경로 | 내용 |
|---|---|
| docs/research.md | 리서치 카드 |
| docs/site-spec.md | 사이트 스펙 (단일 기준 문서) |
| docs/handover.html | 고객 인수인계서 (스펙과 데이터에서 자동 생성) |
| docs/CHANGELOG.md | 변경 기록 (커밋 메시지에서 자동 생성) |
| src/data/ | 업체 정보, 업종 설정, 섹션 순서, 콘텐츠 |
| public/images/ | 생성 이미지 (WebP) |
| marketing/ | 스크린샷, 캐러셀, 릴스, 캡션 (빌드 산출물) |
