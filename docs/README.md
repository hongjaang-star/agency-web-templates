# docs — 프로젝트 기억 저장소

Claude Code 세션은 이전 채팅과 Google 문서를 볼 수 없다. 그래서 지금까지의 기획·결정·작업 이력을 이 폴더에 둔다.

| 파일 | 내용 | 언제 읽나 |
|---|---|---|
| `decisions.md` | 확정된 결정과 바뀐 결정 (최신이 위) | **모든 작업 전에 반드시** |
| `history.md` | 작업 이력, 문제와 해결, 교훈 | 배포·자동화·스크립트 작업 전 |
| `sources.md` | 원본 Google 문서·시트·저장소 주소 | 원본 확인이 필요할 때 |
| `plan/01~06` | Google 설계안 문서 6개 탭의 사본 (01 설계안, 02 운영계획, 03 파이프라인, 04 스펙 표준, 05 자동화, 06 마케팅·수익화) | 해당 주제 작업 시 |

## 우선순위
`decisions.md` > `plan/` 사본. plan 사본 중 decisions.md 와 다른 내용은 오래된 기준이다.

## 갱신 규칙
- 사람이 새 방향을 정하면 `decisions.md` 맨 위에 날짜와 함께 추가하고, 뒤집힌 이전 결정에는 "대체됨"을 표시한다.
- 작업을 끝내면 `history.md` 에 한 줄 추가한다(날짜, 무엇을, 결과, 문제가 있었다면 교훈).
- `plan/` 은 Google 문서의 사본이다. 직접 고치지 말고, 바뀐 내용은 decisions.md 에 쓴다. 사본 갱신은 claude.ai 프로젝트 채팅에서 한다.
