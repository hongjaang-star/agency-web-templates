# edu-academy — 소규모 교육기관 리서치

2026-10-12. 사용자 선택: 소규모 교육기관으로 진행. 건축·스튜디오 hold 유지.

- 목표: 학부모가 과정·활동·운영 방식을 이해하고 상담을 준비하도록 돕기.
- 범위 제안: 초등 독서·사고력 교실. 사용자에게 확정받은 과목은 아니며 조합 선택 시 변경 가능.
- 타깃: 초등 저학년의 첫 수업을 찾는 학부모, 초등 중·고학년의 읽기·토론·표현 과정을 비교하는 학부모.
- 핵심 CTA: 과정 찾기 → 수업 예시 → 상담 준비 메모. 실제 개인정보 접수·반 배정·능력 진단은 하지 않음.
- 키워드 후보: 지역명+독서논술, 지역명+초등 사고력, 지역명+소규모 학원. 검색량은 측정하지 않음.
- 후보 5곳: 한우리, 소마, 폴리인스퍼레이션, 크레버스, 와이즈만. 해외 대체 없음.
- 콘텐츠 A: https://hanuribook.com/program — 학년별 과정, 활동·수업 예시, 교사·상담 흐름.
- 콘텐츠 B: https://new.somai.co.kr/menu/150/page/ — 연령·학년 로드맵, 교재·교구, 설명회·모집 동선.
- 디자인: https://www.polyinspiration.com/ — 큰 메시지, 제목 위계와 이야기 전개. 입자 배경·기업 규모감은 복제하지 않음.
- 공식 본문·메뉴 및 선택한 3곳 데스크톱 캡처 확인. 원본 모바일·속도·접근성 점수 미검증. 와이즈만은 검색 본문만 확인, 직접 읽기 403.
- 시그니처 후보: 첫 수업 카드 / 오늘의 질문 기록 / 첫 방문 안내서.
- 추천 조합 1: 학년·관심 기반 과정 탐색 + 활동 예시 + 상담 준비.
- 대안 조합 2: 교실 활동 기록 중심. 대안 조합 3: 선생님·운영·첫 방문 중심.
- 단계: research, 조합 선택 대기. 선택 후 시안 3개 제작.
- 공통 기준: rules/common.md. edu 전용 규제 파일은 현재 없음. 결과 보장·최상급·가상 성적·합격 실적 미사용. 가상 예시 표시, 이미지·폰트 출처 기록. 실제 폼·가격·운영정보는 납품 범위 확정 후 최신 기준 검토.
- 보고서: concepts/edu-academy/research/index.html. 원본 캡처는 비교 보고서에서만 사용.
