# 사이트 스펙

- 업종 food-cafe / 변형 oven-note / L1 / 첫 변형 flagship.
- 가상 업체 오븐노트38. 목적: 메뉴·브랜드·공간을 보여주는 포트폴리오 데모.
- 색상 cobalt #203fbe, butter #f8df77, cream #fff9ed, coral #f7ac98.
- 서체 Fraunces 500/600 + IBM Plex Sans KR 400/600, 외부 폰트 요청 없이 번들 제공.
- 홈, 메뉴, 오븐의 기록, 저널 목록, 저널 3개 상세, 방문 안내, 개인정보 안내: 총 9페이지.
- 고정 헤더, 360px·768px·1440px 대응, 메뉴 상세 native dialog 및 Escape, 키보드 초점, reduced motion.
- 원본 사진 12장 + 768px 파생본. 이미지 설명, lazy loading, hero 우선 로드.
- 메뉴 필터 4개, 상품 7개, 예시 시간표 3개, 조합 선택 5종 빵 × 2종 음료, 메모 복사와 수동 복사 대안.
- 모든 데모 페이지 noindex, 페이지별 title/description/canonical, sitemap/robots.
- 공통 에디터는 export 후 설치. 사이트 ID와 브라우저 저장 범위를 분리. 앱 간 source import 없음.
- 실주소·연락처·주문·결제·예약·실시간 재고·분석 추적 없음.

검증: 앱 lint/build, 사이트 소스 분리, 에디터 계약, 9개 경로·이미지·모바일 가로 넘침·메뉴/시간/조합/복사 기능을 브라우저에서 확인. 레퍼런스 해석은 research.md에 기록.
