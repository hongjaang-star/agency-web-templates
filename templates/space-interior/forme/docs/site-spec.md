# FORME / 07 사이트 스펙

- 업종: space-interior / 인테리어·리모델링, 변형 forme, L1, flagship.
- 업체: 포름07 공간실험실(가상). 상호 검색 후 선택한 시연용 이름. 실제 주소·전화·자격·시공 실적을 만들지 않는다.
- 목적: 공간 이미지와 재료, 프로젝트 설명을 탐색하고 자신의 상담 우선순위를 정리한다.
- 타깃: 생활 동선과 수납을 바꾸고 싶은 주거 고객, 운영 흐름과 브랜드 분위기를 정리하려는 작은 상업 공간 고객.
- 톤: 차분한, 구체적인, 생활 중심. 확정 가격·기간·결과 보장 금지.
- 디자인: spatial archive, 가로 공간 사진+프로젝트 캡션 히어로, 웜 그레이/올리브/차콜, Pretendard와 Georgia 워드마크. 그리드 선과 얇은 캡션. 기존 세무/의료 화면 소스 공유 없음.
- 시그니처: 재료 분위기 선택, 공간/규모/우선순위/준비 자료에 따른 상담 준비 요약. 실제 견적 계산이나 전송으로 표현하지 않는다.
- 페이지: 18개. 포트폴리오는 오피스·병원·카페·기숙사 각 2개, 신규 상세 8개와 기존 상세 주소 3개를 유지한다. 홈은 공간 소개·주제별 대표 사례·재료·서비스·원칙·과정·상담 준비·FAQ를 포함한다.
- 포트폴리오: 성수/여의도 오피스, 강남/제주 병원, 을지로/양양 카페, 수원/평창 기숙사. 지역·재료·색감·분위기를 구별한다. 상단 라벨·제목·콘셉트·정보, 와이드·중간·디테일 각 2장과 설명, 비대칭 여백을 배치한다. 스크롤 등장·미세 이동·읽기 진행 표시와 사진 확대(화살표 키/Escape)를 제공한다. 모션 감소 설정 및 에디터에서는 사진을 바로 표시한다.
- 진행 과정: 듣기·그리기·만들기·살펴보기 4단계마다 상담·도면/재료·현장 조율·마감 점검 AI 사진을 제공한다. PC는 사진/설명 교차 배치, 모바일은 설명과 사진의 세로 순서. 이미지·캡션은 src/data/process.ts, 프롬프트는 public/images/process/source.json.
- 이미지: 포트폴리오 전용 AI 사진 48장과 반응형 WebP 48장, 기존 사진 3장 보존. 다나함 works는 사진·설명 배치 참고에만 사용했으며 이미지나 시공 실적을 복제하지 않는다. 출처·프롬프트·원본 해시는 public/images/portfolio/source.json.
- SEO: 페이지별 title/description, Organization JSON-LD, sitemap, robots 및 demo noindex. 정적 export와 환경변수 basePath.
- 운영: 데이터/이미지 변경은 앱 내부. 공통 editor/는 빌드 설치, siteId=space-interior/forme. 브라우저 저장과 JSON 배포 구분.
