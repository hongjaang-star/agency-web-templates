# 이미지 출처

living.webp, cafe.webp, kitchen.webp는 이번 포트폴리오용으로 OpenAI 이미지 생성 도구에서 새로 제작한 가상 공간 이미지다. 실제 업체·프로젝트 사진을 복제하지 않았다. 실제 시공 실적이나 사용자 후기로 표시하지 않는다.

원본 PNG에서 RGB WebP로 최적화했다. 포트폴리오 썸네일은 완성된 사이트의 실제 브라우저 화면 캡처다.

서체 Pretendard는 npm pretendard 패키지(SIL Open Font License)를 사용한다. Georgia는 시스템 서체이며 서체 파일을 별도로 배포하지 않는다.
