# 질문결 Orbit · 어린이 표현과 이미지 기획 1.1

## 레퍼런스 해석
대교 눈높이 공부방·교습소 https://noonnoppi.daekyo.com/channel-service/NC 를 2026-10-13 확인.
고민을 짧게 묻기 → 학습 방식 설명 → 장점·학습 도구를 이미지 카드로 안내 → 학습 과정 → 상담의 흐름과, 큰 제목·둥근 카드·사진·일러스트 조합을 참고.
질문결에는 ‘작은 궁금함 → 읽기/말하기/쓰기 탐험 → 학년별 과정 → 활동 장면 → 배움 꾸러미 → 학부모 기록’으로 새로 설계. 눈높이 로고·색·원본 이미지·카피·성과 주장은 가져오지 않음.

## 디자인 시스템
초등학생은 재미있는 책의 세계와 짧은 활동 문장으로, 학부모는 구체적 과정·자료·학습 기록으로 이해하도록 두 층의 전달을 연결.
아이보리 #f7f6ee, 잉크 올리브 #283f31, 세이지·연올리브 중심 유지. 연살구 #efc6a5·연보라 #d8d9ec는 보조 영역.
제목은 둥근 Jua, 본문은 Gowun Dodum, 소형 영문은 Manrope. 24–35px 둥근 모서리, 말풍선, 책/대화/연필/새싹의 독자 SVG 모티프.

## 이미지 세트
1. book-garden-v2.webp: 펼친 책에서 숲과 이야기 길이 자라는 종이공예·클레이 일러스트. 첫 화면의 대상과 독서 탐험을 표현. 인물·문자 없음.
2. reading-together-v2.webp: 머리 위에서 내려다본 초등 수업. 책·그림카드·노트와 세 학습자의 손/뒷모습으로 읽기·토론·쓰기를 전달. 얼굴이 식별되지 않는 일러스트, 실사 아님.
3. learning-kit-v2.webp: 읽기책·질문카드·배움노트를 무문자 가상 제품으로 제시. 정확한 제목·설명은 HTML 텍스트로 별도 제공.
세 이미지는 OpenAI ImageGen으로 신규 제작, 같은 색·종이 질감·작은 책갈피 새의 아트 디렉션 적용. WebP는 원본의 시각 내용을 바꾸지 않고 포맷 인코딩만 함. 원본 파일명과 전체 프롬프트는 assets-manifest.json 기록.
교실의 실제 느낌은 기존 가상 공간 사진을 소개 영역에서 유지. 아이 얼굴이 드러나는 실사 사진은 쓰지 않음.

## 전달과 기능
단순 장식 대신 교육 행동과 연결: 독서=단서 발견, 토론=이유 듣기, 글쓰기=내 결말 만들기.
‘수업 맛보기’ 3탭은 클릭/좌우키/Home/End로 이동하며, 힌트 펼치기를 제공. 채점·입력·학습 평가 기능 없음. 학년별 기존 과정과 학부모 안내의 상세 콘텐츠 유지.
