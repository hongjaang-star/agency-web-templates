## 1.2 · 메뉴 가독성과 3D 이미지
- 사용자 화면 977px 기준 주요 메뉴 11px → 16px. 넓은 화면 17px, 모바일 펼친 메뉴 18px.
- 상세 14페이지 상단 선 그림을 주제별 3D 이미지로 교체. 모바일에서도 이미지 표시.
- 읽기/말하기/글쓰기 단계는 돋보기 단서 찾기/말풍선 생각 나누기/연필 이야기 만들기의 신규 3D 이미지로 교체.
- 추가 신규 이미지: 배움의 성장 길, 집에서의 대화. 총 5종을 built-in OpenAI ImageGen으로 제작. 전체 프롬프트와 원본 경로는 assets-v3-manifest.json. 기존 일러스트와 아이보리·올리브 색감 유지.

## 1.3 · 상담 버튼과 시간표
- 전체 15페이지 PC 왼쪽 아래 / 모바일 하단 고정 카톡·전화 상담 버튼. 실제 채널·번호 미제공으로 데모 안내 dialog 표시. Escape·닫기·안내 이동 시 닫힘. contact.json의 kakaoUrl/phone을 등록하면 채널 새 창 및 tel 링크 연결.
- 홈·교육과정·첫 수업 안내와 과정 상세 3페이지에 연령/학년·정원·주당 횟수·회당 시간과 화/목/토 주간 시간표 추가. 학년 필터 지원.
- 씨앗결 만6–8세/초1–2/6명, 가지결 만8–10세/초3–4/6명, 나무결 만10–12세/초5–6/8명. 모두 주1회90분, 화·목·토 중 한 반 선택. 연령은 취학 범위 예시, 학년·읽기 경험 우선. 운영 예시이며 모집 정보 아님.
- 실제 화면 HTML 원본은 site.json, 구조화 시간표 참고 데이터는 schedule.json. 시간표를 변경하면 양쪽을 함께 수정.
