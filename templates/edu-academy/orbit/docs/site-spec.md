## 1.2 · 메뉴 가독성과 3D 이미지
- 사용자 화면 977px 기준 주요 메뉴 11px → 16px. 넓은 화면 17px, 모바일 펼친 메뉴 18px.
- 상세 14페이지 상단 선 그림을 주제별 3D 이미지로 교체. 모바일에서도 이미지 표시.
- 읽기/말하기/글쓰기 단계는 돋보기 단서 찾기/말풍선 생각 나누기/연필 이야기 만들기의 신규 3D 이미지로 교체.
- 추가 신규 이미지: 배움의 성장 길, 집에서의 대화. 총 5종을 built-in OpenAI ImageGen으로 제작. 전체 프롬프트와 원본 경로는 assets-v3-manifest.json. 기존 일러스트와 아이보리·올리브 색감 유지.
