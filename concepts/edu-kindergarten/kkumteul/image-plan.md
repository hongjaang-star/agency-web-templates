## 적용 기준

- 14개 3D 장면과 4개 공간 장면. 각 이미지에 본문용 WebP와 800px 소형 WebP를 제공한다.
- 데스크톱 메인은 왼쪽 문구·오른쪽 활동 구도를 활용한다. 모바일에서는 위 이미지·아래 문구로 나눈다.
- 교육환경에서만 4개 실사풍 이미지를 선택한다. 동일 주제라도 메인·활동 카드는 3D를 사용한다.
- 실사풍 공간은 AI가 생성한 가상 예시이며 실제 유치원 시설 사진이 아니다. 교육환경 안내와 대체 텍스트에 표시한다.
- 이미지 대체 텍스트, 지연 로딩, 첫 메인 이미지 우선 로딩, 반응형 srcset을 제공한다.
- 게시판·신청 폼·기존 정보는 유지한다.

## 검증 범위

스크립트 구문, 전체 해시 경로의 HTML 생성, 이미지 파일 및 srcset 경로, 공간 이미지 선택, 사이트 소스 분리, 포트폴리오 빌드를 검사한다. 이 환경에는 지원되는 브라우저 제어 도구가 없어 실제 화면·클릭 동작 QA는 수행하지 못했다.
