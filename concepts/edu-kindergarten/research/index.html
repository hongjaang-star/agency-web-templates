1. 업종 정의와 검색 결과

범위: 만 3~5세 대상 사립(또는 법인) 유치원. 홈페이지를 직접 운영하며 입학 상담·견학으로 원아를 모으는 곳을 기준으로 합니다. 공립은 교육청 표준 템플릿을 쓰므로 정보 구조 비교에만 활용했습니다.

학부모가 홈페이지에서 확인하는 것: ① 아이가 하루를 어떻게 보내는지 ② 교육 철학과 공간(실내·실외) ③ 식단·통학·안전 ④ 비용과 지원(누리과정) ⑤ 입학 일정과 견학·상담 방법.

검토 후보: 오산숲유치원(공립·교육청 템플릿), 미래유치원(사립·레지오 에밀리아), 동탄숲유치원(접속 반복 리다이렉트로 본문 확인 불가), 아뜰리에유치원(로봇 차단으로 확인 불가), 쥬니버스쿨(GDWEB 2024 WINNER·귀여운·옐로, 페이지 접근 차단), LG유플러스 아이들나라(GDWEB 2022 BRONZE, 현재 다른 페이지로 이동), MEplace Childcare(영국, Awwwards 수록), 유치원 알리미·처음학교로(공식 정보 서비스, 링크 대상).

디자인 참고를 해외에서 고른 이유: 국내 GDWEB 유아·아동 선정작은 현재 페이지가 닫혀 있거나 접근이 막혀 화면 구성을 확인할 수 없었습니다. 그래서 Awwwards에 수록된 MEplace Childcare로 대체했습니다. 아래 도식은 확인된 정보 구조를 요약한 것이며 실제 화면 캡처가 아닙니다.

4. 조합 제안

조합 1 · 추천

우리 아이의 하루형

콘텐츠 조합
A의 식단·일정·통학 실무 정보 + B의 철학·공간 이야기를 '하루 시간표'에 엮음.
디자인 조합
MEplace의 기하 도형과 번호 카드를 시계·시간 블록으로 변주.
대표 구성
하루 시계 → 교육 철학과 공간 → 반·연령별 과정 → 식단·통학·안전 → 입학 안내(일정·비용 안내·견학) → 알림.
시그니처 후보
08:30 등원부터 16:30 방과후까지 시간대를 누르면 장소·활동·오늘 간식이 바뀌는 '하루 시계'.
추천 이유
학부모의 첫 질문 "우리 아이가 여기서 하루를 어떻게 보내나"에 바로 답하고, 실무 정보도 자연스럽게 이어짐.
조합 2

철학·계절 놀이 이야기형

콘텐츠 조합
B의 레지오·숲 철학과 공간 + A의 방과후 반별 놀이 이야기.
디자인 조합
MEplace의 가치 카드·사진 릴을 계절 탭과 놀이 기록 카드로.
대표 구성
철학 한 문장 → 계절 놀이 지도 → 프로젝트 기록(아이의 질문 → 활동) → 교사 → 입학.
시그니처 후보
봄·여름·가을·겨울 탭으로 실내·실외 공간 지도가 바뀌는 '계절 놀이 지도'.
장점과 부담
브랜드 감성이 강하고 사립 차별화에 좋음. 놀이 기록 글을 꾸준히 써야 함.
조합 3

학부모 알림판형

콘텐츠 조합
A의 알림마당(식단·행사·가정통신문·통학)을 메인 대시보드로.
디자인 조합
MEplace의 번호 카드와 상시 문의 버튼을 위젯형 보드에.
대표 구성
오늘 보드(식단·날씨 활동·차량) → 이번 달 달력 → 가정통신문 → 입학 준비 체크리스트 → 원 소개.
시그니처 후보
월간 행사 달력 + 입학 일정 D-day와 준비물 체크리스트.
장점과 부담
재원생 학부모가 매일 쓰기 좋음. 신규 원아 모집용 감성 표현은 약함.

5. 업종 표기·주의 사항

  • 아이 얼굴이 나오는 실사 사진(실존·AI 모두)은 쓰지 않고 도형·일러스트·뒷모습·사물로 표현합니다.
  • 원비·누리과정 지원 금액은 해마다 바뀌므로 수치를 단정하지 않고 '유치원 알리미 공시 기준 확인'으로 안내합니다.
  • 입학 신청은 '처음학교로'(유보통합 이후 통합 포털 포함) 일정과 연결하고, 데모에서는 실제 접수를 받지 않습니다.
  • '안전 100%', '최고의 교육' 같은 단정 표현 금지(rules/common.md). 급식은 알레르기 유발 식품 표기 예시를 둡니다.
