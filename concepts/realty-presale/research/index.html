5. 기본 메뉴와 메뉴별 카피 방향

분양 사이트 기본 7메뉴에 관심고객 등록을 항상 고정합니다. 탭을 눌러 메뉴마다 화면 첫머리 예시 · 하위 메뉴 · 반드시 붙일 고지 · 행동 버튼을 확인하세요.

카피 말투 원칙

  • 장면으로 말하기: “최고의 입지” 대신 “숲길로 등교하고, 역까지 걸어가는 아침”
  • 숫자에는 근거: 거리 · 시간 · 면적 옆에 기준점 · 기준일을 작게
  • 단정하고 따뜻한 존댓말: 외침표 · 과장 형용사 대신 짧은 평서문
  • 계획은 계획이라고: ‘예정 · 계획 · 추진 중’ 단서를 같은 줄에
  • 제목은 15자 안팎: 모바일 첫 화면에서 두 줄을 넘기지 않기
  • 행동 버튼은 동사로: “관심고객 등록하기”, “방문 예약하기”, “전화 상담”

6. 홍보 마케팅 시나리오 단계마다 메인 히어로 · 팝업 · 문자 · 광고 채널이 바뀜

사이트는 하나, 단계(phase) 값만 바꾸면 메인 첫 화면과 팝업, 고정 버튼의 우선순위가 함께 바뀌게 설계합니다. 단계를 눌러 보세요.

채널 운영 원칙

  • 검색광고: “가람신도시 아파트”, “가람 분양”, “가람숲 59㎡” 같은 지역 + 타입 키워드. 랜딩은 메인이 아니라 해당 타입 · 입지 페이지로 바로.
  • 소셜 · 디스플레이 광고: 단계별 소재 3종(입지 장면 / 타입 평면 / 일정). 등록하지 않은 방문자에게만 재노출.
  • 블로그 · 카페 정보 글: “가람신도시 청약 일정 정리”처럼 정보형. 광고 글은 “광고” 또는 “협찬”을 제목 · 첫 줄에 밝힘.
  • 현수막 · 전단 · 견본주택 QR: 매체별 UTM 주소를 따로 써서 오프라인 효과도 숫자로 봄.
  • 문자 · 카카오 알림: 광고 수신에 동의한 등록자에게만, 맨 앞 (광고), 무료 수신거부 번호, 오후 9시~오전 8시는 별도 야간 동의자에게만.
  • 주간 리뷰 지표: 방문 → 등록 전환율, 전화 클릭 수, 방문 예약 → 실제 방문율, 단계별 문자 수신거부율. 가장 낮은 단계부터 카피 · 소재를 바꿈.

7. 쉽게 문의하는 동선

경로 1 · 가장 짧게

전화 상담

모든 화면 고정 버튼. 누르면 바로 전화(tel:). 홍보관 운영 시간 밖이면 “지금은 상담 시간이 아니에요. 등록하시면 내일 오전에 연락드려요”로 안내.

경로 2 · 주력

관심고객 등록

이름 · 휴대폰 2칸 + 필수 동의 1개. 관심 타입 · 방문 희망일은 선택. 페이지를 떠나지 않는 하단 시트로 열림.

경로 3 · 방문 전환

방문 예약

날짜 → 30분 단위 시간 → 인원. 예약 완료 화면에서 지도 앱 열기 · 캘린더 추가.

경로 4 · 부담 없이

카카오톡 상담

채널 채팅으로 바로 연결. 전화가 부담스러운 30대와 야간 방문자용.

관심고객 등록 (데모 · 접수 안 됨)

전화관심고객 등록방문 예약카카오톡

문의 전환을 높이는 장치

  • 입력칸은 2개가 기본. 칸이 하나 늘 때마다 이탈이 늘어난다는 점을 전제로, 나머지는 등록 뒤 상담 전화에서 묻기
  • 휴대폰 번호는 숫자 키패드(inputmode), 하이픈 자동 정리, 형식 오류는 칸 바로 아래 한 줄로
  • 동의는 필수 1개 + 선택 2개로 분리, 선택 동의를 하지 않아도 등록됨
  • 등록 완료 화면: “오늘 안에 연락드릴게요” + 방문 예약 · 카카오 채널 · 사업개요 PDF 다음 행동 3개
  • 광고 매체(UTM) · 들어온 페이지 · 관심 타입을 숨은 값으로 저장해 상담 때 바로 봄
  • 스팸 막기: 사람에게 보이지 않는 함정 칸 + 같은 번호 하루 1회 제한(서버). 문자 인증은 전환을 깎으므로 쓰지 않음
  • 전화 클릭 · 등록 · 예약 완료를 분석 이벤트로 기록해 단계별 전환을 측정
