1. 검색 범위와 결과

네이버 검색 상위 프로필·증명사진 스튜디오와 GDWEB 선정작에서 찾았습니다. 국내에서 조건에 맞는 사이트를 찾았기 때문에 해외 사이트로 넓히지 않았습니다.

검토한 후보 10곳: 시현하다, 스튜디오피플, 스튜디오 임프레스, 우리동네사진관, 스튜디오한, 시타스튜디오, WS디자인스튜디오, 스튜디오JT, 스튜디오 톰보이, 스튜디오 파티클

확인 방법 한계: 이 작업 환경은 외부 사이트 접속이 막혀 있어 화면을 직접 열거나 캡처하지 못했습니다. 메뉴·구성은 검색 엔진이 수집한 페이지 목록과 공개 자료(GDWEB 선정 설명, 기사)로 확인했고, 카드의 그림은 캡처 대신 확인된 구조를 옮긴 도식입니다. 서체·색 같은 세부 화면 인상은 직접 확인이 필요합니다.

3. 5개 주제 비교

주제A · 시현하다B · 스튜디오피플디자인 · 스튜디오 파티클우리 사이트에 가져올 점
정보 구조메뉴 9개, 브랜드·예약·스토어·매거진용도별 촬영 메뉴 + 가격·영상 페이지프로젝트 목록 중심촬영은 용도별로 나누고, 가격은 한 페이지에서 비교
콘텐츠와 메시지"배경색" 한 가지 특징, 사람 이야기직업·목적별 맞춤, 1:1 상담숫자로 규모 요약스튜디오만의 특징 하나를 정하고 끝까지 반복
전환 경로자체 예약 페이지, 월 단위 예약네이버 플레이스 예약, 예약금·잔금 안내해당 없음상품을 고른 자리에서 바로 외부 예약으로 연결
비주얼 디자인직접 확인 필요직접 확인 필요모션그래픽, 큰 타이포, 실험적 레이아웃결과물 사진과 큰 글자가 함께 움직이는 화면
모바일과 사용성SNS·지점별 예약 병행가격표 단순화(컷 수 기준)직접 확인 필요가격 비교는 모바일에서 세로 카드로, 모션은 줄이기 옵션 제공
