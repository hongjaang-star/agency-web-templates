1. 업종 선정과 검색 결과

대기열에서 청소·방역·이사 다음의 첫 대기 업종입니다(청소업종은 시안 선택 대기). 추천 제작 범위는 중소기업·소상공인 대상 경영·조직(HR) 부티크 컨설팅입니다. 대형 전략 컨설팅과 정책자금 대행은 대상 고객과 표현 위험(확보액·승인률 강조)이 달라 제외했습니다.

검토 후보: KMAC(한국능률협회컨설팅), 한국생산성본부(KPC) 조직&HR, BX컨설팅, 채움경영컨설팅, HR체인지, 비즈파트너즈, SBKM 중소기업 지식경영센터, 이퓨전아이(GDWEB 2026 선정), 인스플래닛(GDWEB 2026 선정). BX컨설팅은 과제별 서비스→사례→인사이트, 채움경영컨설팅은 소규모 기업을 위한 비용·지원사업·강좌 안내로 정보 구조가 서로 달라 콘텐츠 참고로 골랐습니다. KMAC·KPC는 대기업·공공 대상으로 메뉴가 방대해 구조 비교에만 썼고, HR체인지는 403 응답으로 본문을 확인하지 못했습니다. 비즈파트너즈는 누적 건수·확보 금액을 앞세우는 방식이라 이 업종 규제(rules/pro.md)와 맞지 않아 제외했습니다. 국내에서 3곳을 찾았으므로 해외 대체는 없습니다.

확인 범위: 공식 사이트와 GDWEB 선정작 페이지의 본문·메뉴·링크를 2026-10-09에 확인했습니다. 아래 그림은 확인된 정보 구조를 요약한 도식이며 실제 화면 캡처가 아닙니다. 색상·애니메이션·모바일 화면은 직접 검증하지 못했고, 디자인 카드의 적용안은 기획 제안으로 구분했습니다.

2. 레퍼런스 카드

콘텐츠 참고 A

BX컨설팅

bxcon.co.kr · 공식 사이트 열기 ↗
서비스수행사례인사이트회사소개
과제별 히어로 3장 → 서비스 카드 7개
교육 → 사례 3건 → 인사이트·리포트 → 네트워크 → 고객 로고
확인된 구조 요약 · 캡처 아님
  • 대상: 중견·대기업의 영업·고객경험·조직 담당자.
  • 과제(영업 전략·고객경험·AI) 단위로 서비스를 나누고 카드로 진입.
  • 서비스 상세는 고객의 문제 → 진단·설계 항목 순으로 설명.
  • "프로젝트 문의"를 섹션마다 반복, 팝업 폼에서 과제 분류를 고르게 함.
  • 세일즈 영역에 셀프 진단 도구, 인사이트 레터·기획조사로 전문성 표현.

가져올 점: 과제 → 프로그램 → 사례 → 인사이트의 흐름과 문의 시 과제 분류. 고객사 로고·실적은 가상 업체로 옮기지 않습니다.

메인 비주얼 → 회사·멤버·강의 바로가기

확인된 구조 요약 · 캡처 아님
  • 대상: 소상공인과 중소기업 대표.
  • "컨설팅의 개념과 계약 원리", 비용·지원사업 구분을 별도 페이지로 설명.
  • 국책 지원과 개별 의뢰를 나누고, 개별 의뢰는 범위·기간에 따라 협의한다고 안내.
  • 대표 컨설턴트·스태프를 메뉴로 두어 사람 중심 신뢰를 만듦.
  • 무료 온라인 강좌와 자료실로 상담 전 접점을 제공.

가져올 점: 비용 구조와 계약 원리의 투명한 설명, 컨설턴트 소개, 자료실. 지원 비율 등 수치는 공고마다 달라 데모에 단정하지 않습니다.

4. 조합 제안

조합 1 · 추천

과제 진단·프로그램 선택형

콘텐츠 조합
BX컨설팅의 과제별 서비스·문의 분류 + 채움경영컨설팅의 비용·계약 원리 안내.
디자인 조합
이퓨전아이의 대비 타이포를 "지금의 문제 → 다음 체계"로 바꿔 첫 화면에 사용.
대표 구성
과제 진단 → 추천 프로그램(범위·기간·산출물) → 진행 절차 → 비용 안내 → 상담 메모.
시그니처 후보
5~6문항 자가 진단으로 과제 영역과 준비 자료가 정리되는 도구.
추천 이유
컨설팅은 "무엇을 사는지"가 보이지 않는 서비스. 상담 전 범위·산출물을 이해시키기 좋고 결과 보장 없이도 전문성을 보여 줌.
선택할 때
여러 프로그램을 가진 소규모 컨설팅사를 소개하는 경우.
조합 2

인사이트·사례 매거진형

콘텐츠 조합
BX컨설팅의 인사이트 레터·수행사례 + 채움경영컨설팅의 무료강좌·자료실.
디자인 조합
이퓨전아이의 그리드와 이미지 전환을 아티클·사례 카드에 적용한 편집형 화면.
대표 구성
대표 글 → 주제별 인사이트 → 유형별 사례(가상) → 자료 받기 → 상담.
시그니처 후보
업종·규모·과제로 거르는 사례 보드와 읽는 시간 표시 아카이브.
장점과 부담
검색 유입과 전문성 표현에 강함. 글 콘텐츠 제작량이 많고 사례는 가상 예시임을 명시해야 함.
선택할 때
콘텐츠 마케팅으로 고객을 모으는 컨설팅사인 경우.
조합 3

컨설턴트·방법론 중심형

콘텐츠 조합
채움경영컨설팅의 대표 컨설턴트·함께하는 분 + BX컨설팅의 진단·설계 항목.
디자인 조합
이퓨전아이의 두 이미지 전환을 "인물 ↔ 작업 도식" 카드로. 차분한 서체와 넓은 여백.
대표 구성
대표 컨설턴트 → 일하는 방식(단계별 산출물) → 전문 분야 → 강의·자료 → 상담.
시그니처 후보
진단·설계·정착 단계를 스크롤하면 단계별 회의·산출물이 쌓이는 방법론 타임라인.
장점과 부담
1인·소수 전문가 사무소에 맞음. 인물 사진(가상)과 자격 표기 정확성이 중요.
선택할 때
경영지도사 등 대표 개인의 전문성으로 영업하는 경우.
