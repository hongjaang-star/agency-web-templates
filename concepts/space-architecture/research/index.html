1. 검색 범위와 결과

네이버·웹어워드코리아·GDWEB 수상 목록, 건축 매체(SPACE, ArchDaily 사무소 페이지)에서 국내 사무소를 찾았습니다. 국내에서 조건에 맞는 사이트를 찾았기 때문에 해외 사이트로 넓히지 않았습니다.

검토한 후보 9곳: 해안건축, PA종합건축사사무소, 매스스터디스, 페이퍼비 건축사사무소, 라움 건축사사무소, 김이홍아키텍츠, 바우건축, 건축공방, Architecture Studio YEIN

확인 방법 한계: 이 작업 환경은 외부 사이트 접속이 막혀 있어 화면을 직접 열거나 캡처하지 못했습니다. 메뉴·구성은 검색 엔진이 수집한 페이지 목록과 공개 자료(사무소 페이지 제목, 디자이너의 작업 설명)로 확인했고, 카드의 그림은 캡처 대신 확인된 구조를 옮긴 도식입니다. 서체·색 같은 세부 화면 인상은 직접 확인이 필요합니다.
